# User guide

## Front desk

1. Sign in as `R_Admin`. If Google Authenticator is not set up, scan the code and save the recovery codes.
2. Add the owner, then the pet. Set the pet status to Active, Caution, Inactive, or Deceased.
3. Book the appointment. The same veterinarian cannot be booked twice at the same time. A cancelled visit does not hold the slot.
4. At checkout, take payment from Billing. A deleted invoice stays in the recycle bin and can be restored by an administrator.
5. To remove an owner, pet, or appointment from the daily lists, delete it. An administrator can restore it from Recycle Bin.

## Veterinarian

1. Open the appointment and start the consultation.
2. Record the diagnosis and the prescription. Dosage is required before the prescription is saved by the form.
3. A prescription can be moved to the recycle bin. It cannot be erased.
4. Do not send a reminder for a pet marked Deceased or Inactive. The server skips those.

## Everyone

- Sign out at the end of the shift. Signing out ends other sessions for that same account.
- Backup status is on the administrator Health page. Tell the administrator if that page says the backup needs attention.

# When the system is down

If the clinic PC or the network is unavailable, see patients on paper and enter the visits when Bayport is back.

## Paper slip

- Date and time
- Owner name and phone
- Pet name, species, and status
- Veterinarian
- Reason for the visit, diagnosis, and medicines with dose
- Amount charged and amount received

Keep the slips in one folder for that day.

## After Bayport is back

1. Confirm the server is running and the backup bar is clear.
2. Enter each slip as an owner, pet, appointment, consultation, prescription, and payment.
3. Mark the slip as entered.
4. Take a backup when the folder is empty.
